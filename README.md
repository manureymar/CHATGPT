# Ridge Rush: Turbo Trails

Juego Android nativo 2D creado para este proyecto. Incluye cinco circuitos, física de vehículo, combustible, monedas, mejoras y progreso local.

- Android nativo (Java + Canvas 2D)
- minSdk 23
- targetSdk 36
- compileSdk 36
- JDK 17

El APK de prueba se compila automáticamente con GitHub Actions.
